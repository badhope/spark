# Spark

Browser-native, cross-platform, open-source AI coding and office workbench, with guardrails you can audit.

[English README](https://github.com/badhope/spark/blob/main/README.md) · [中文 README](https://github.com/badhope/spark/blob/main/README_zh.md) · [English docs index](en/README.md)

Spark runs where you choose — your laptop, a server, or a self-hosted relay — and works with any OpenAI-compatible endpoint. Writes and commands pass through approval and a sandbox; each turn can be rolled back; the same agent loop serves the Web UI, terminal, desktop, IDE, mobile layout and API.

- Install: `uvx spark-agent` or the [platform installer](en/INSTALL.md)
- Start: `spark web`
- Read next: [features](FEATURES.md), [architecture](en/ARCHITECTURE.md), [API](en/API.md)
