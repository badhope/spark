# Spark

<p align="center">
  <img src="https://raw.githubusercontent.com/badhope/spark/main/brand/hero-en.webp" alt="Spark — one agent loop, every surface you code on" width="100%">
</p>

One agent loop across Web, desktop, CLI, IDE and phone. Browser-native, approval-gated, self-hosted. Your keys, code and context stay yours.

Writes and commands pass through approval and a sandbox; each turn can be rolled back; the same agent loop serves the Web UI, terminal, desktop, IDE, mobile layout and API.

- Install: `uvx spark-agent` or the [platform installer](en/INSTALL.md)
- Start: `spark web`
