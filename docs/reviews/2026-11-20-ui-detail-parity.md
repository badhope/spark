# Spark Web UI 细节对标清单（2026-11-20）

> 范围：ChatGPT / Claude / DeepSeek / Kimi / 豆包等通用 AI 对话产品，以及 Cursor / Claude Code / Codex / opencode 等编码 Agent 的 Web 界面。
> 目的：把“思考时间”之外的界面微交互也逐项过一遍，避免只补一个点、其余细节继续漏。
> 版本：Spark `0.15.2`（本轮不 bump）；前端入口 `index-DAp0XIc8.js`（收口构建）。

## 结论

- 本轮不是只补“思考时间”，而是按消息层、流式/滚动、输入框、会话栏、工具与工作台、首屏与可访问性六个层面做了完整巡检。
- 本轮新增/修复 7 处聊天区细节：回到底部/新输出提示、子任务耗时、工具结果复制、上下文用量环可点击、首屏骨架与“连接中”态、会话切换滚动位置重置、顶部工具菜单的导出/分享入口。
- 第二轮继续把“其他领域”补齐：工作台移动端抽屉化、文件树/文件查看器搜索、文件预览复制路径/内容/下载、变更面板搜索+定位+复制 diff、终端复制选中/清屏、网页阅读复制正文/重抓/打开原页、Replay/Checkpoint 刷新与 Replay 复制、设置页全局搜索、主要弹窗 `aria-modal`。
- 第三批补齐消息元信息、文本附件、SSE 续接、执行图、检查点、网页阅读、终端、CSP/PWA。
- 第四批补齐 `@` 目录树、全站 Modal focus trap、队列任务时间戳；并修掉两个真实交互 bug：选中文件后 `@` 菜单不关闭、`..` 返回上级路径少一级。
- 仍有一些明确未做项，已列在下方矩阵的“下一步”列，按 P1/P2/P3 排序，不会因为本轮结束而丢失。

## 明确不跟进（沿用既有评审）

- Mermaid 图渲染：编码 Agent 场景收益低，依赖体积大。

- LSP 全量 IDE 能力、云端沙箱、Tab 补全、Git PR 工作流：见 `2026-11-07-ecosystem-audit.md`，本轮不重新打开。
